# GM Soundboard — веб-версія (Cloudflare Workers)

Той самий саундборд, але в браузері: дві дошки (Night City, Elysium), 24 звуки CC0,
редактор слотів, свої файли, теми.

Відмінності від програми для Windows:
- хоткеї (Ctrl+Alt+1…=, Ctrl+Alt+Space) працюють, лише коли вкладка відкрита й активна;
- дошки, налаштування й додані тобою звуки зберігаються в цьому браузері;
- у Safari старі версії не відтворюють OGG — краще Chrome, Edge або Firefox.

## Публікація
Двічі клікни `deploy.cmd`. Перший раз відкриється браузер для входу в Cloudflare.
Наприкінці wrangler покаже адресу на кшталт `https://gm-soundboard.<твій-субдомен>.workers.dev`.

Або вручну: `npx wrangler deploy` у цій папці.

## Зміни
Інтерфейс спільний із десктопною версією (`gm-soundboard/ui`). `python build.py` збирає `public/`.
