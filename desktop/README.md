# GM Soundboard

Саундборд для майстра НРІ з глобальними гарячими клавішами. Має дві стартові дошки: **Night City** (Cyberpunk 2077) і **Elysium** (Vampire: The Masquerade).

## Що вміє

- **Дошки (пресети).** На кожній дошці 12 слотів. Перемикаються кліком по вкладці, і при перемиканні весь звук плавно зупиняється.
- **Глобальні хоткеї.** `Ctrl+Alt+1…0, -, =` запускають слоти 1–12 активної дошки. Працюють, навіть коли у фокусі Foundry, Roll20, Discord або браузер. Від розкладки (UA/EN) не залежать.
- **Silence** (`Ctrl+Alt+Space`) зупиняє все з коротким фейдом.
- **Два типи звуків:**
  - **SFX** — одноразовий звук;
  - **Loop** — ембієнт у циклі з fade in/out.
- **Повторне натискання** налаштовується для кожного слота:
  - *Overlap* — накласти ще одну копію (для пострілів);
  - *Restart* — почати спочатку;
  - *Stop* — зупинити (для ембієнту).
- **Гучність:** окремо для кожного слота, канали SFX та Ambient, Master.
- **Індикація.** Слоти, що грають, підсвічуються, внизу видно прогрес. Якщо копій кілька, показується лічильник ×N.
- **Теми.** Кожна дошка має свою: *Neon / Cyber*, *Gothic / Blood* або *Neutral*.
- **Редактор.** Кнопка **Edit** (або клавіша `E`): клік по слоту відкриває редактор, слоти можна міняти місцями перетягуванням, тут же налаштовуються дошки. Правий клік по слоту відкриває редактор і поза режимом Edit.

## Як зібрати .exe (один раз)

1. Встанови **Python 3.12** з https://www.python.org/downloads/ і постав галочку *Add python.exe to PATH*. Підходять версії 3.11–3.13. На 3.14 збірка поки не працює.
2. Розпакуй цю папку куди завгодно і запусти **`build.bat`**. Перший раз він триватиме 2–5 хвилин.
3. Готова програма з'явиться в `dist\GMSoundboard\GMSoundboard.exe`. Цю папку можна перенести куди зручно, але **не в Program Files**: програма зберігає дошки й звуки поруч із собою.

> Windows SmartScreen може попередити, що програма «невідомого видавця», бо `.exe` не підписаний. Натисни *Детальніше → Все одно запустити*. Деякі антивіруси помилково реагують на програми, зібрані через PyInstaller.
>
> Для вікна потрібен Microsoft Edge WebView2. У Windows 10/11 він зазвичай уже встановлений. Якщо ні: https://developer.microsoft.com/microsoft-edge/webview2/

Щоб запускати без збирання, після першого `build.bat` можна просто запускати `run.bat`.

## Стартові звуки (Freesound, CC0)

Звуки не входять у збірку. Програма сама завантажує їх із freesound.org, і лише з ліцензією CC0, тобто суспільне надбання без жодних вимог.

1. Зареєструйся на https://freesound.org і отримай безкоштовний API-ключ: https://freesound.org/apiv2/apply. Подай заявку на *API credentials*: назва будь-яка, наприклад «GM Soundboard»; скопіюй **Client secret/Api key**.
2. У програмі відкрий **Settings → Starter sounds**, встав ключ і натисни **Download missing sounds**.
3. Звуки з'являться у слотах відразу, перезапуск не потрібен.

Якщо якийсь звук не сподобався, відкрий цей слот у редакторі й натисни **↻ Re-roll**: програма підбере інший варіант. Кнопка **Re-roll all** замінює всі стартові звуки. Хто автор кожного звуку, видно в `sounds\starter\CREDITS.txt`.

Те саме можна зробити з командного рядка: `python download_sounds.py ТВІЙ_КЛЮЧ`.

На дошці **Elysium** запити складені так, щоб відсікати музику: `-music -song -melody…`. Якщо щось музичне все ж проскочить, зроби Re-roll цього слота.

## Свої звуки

У режимі **Edit** клікни по слоту, потім **Choose file…**. Підтримуються формати OGG, WAV, MP3 і FLAC. Файли з інших папок копіюються в `sounds\custom\`, тож папку програми можна переносити на інший ПК цілком.

## Гарячі клавіші

**Settings → Hotkeys**:

- **Модифікатор.** Можна поміняти Ctrl+Alt на інший (Ctrl+Shift, Alt+Shift тощо). Модифікатор обов'язковий, інакше хоткеї перехоплювали б звичайний набір тексту в усіх програмах.
- **Клавіші слотів.** Клікни по слоту й натисни нову клавішу. ✕ знімає призначення.
- **Конфлікти.** Якщо комбінацію вже зайняла інша програма, Windows про це повідомить. Слот підсвітиться червоним, а внизу з'явиться лічильник конфліктів.

> На українській розкладці `Ctrl+Alt` — це те саме, що `AltGr`. Тому `AltGr+1` теж запустить слот 1. Якщо через це щось заважає, зміни модифікатор на `Ctrl+Shift`.

## Файли

```
GMSoundboard\
  GMSoundboard.exe
  presets.json        ← дошки та слоти (читабельний JSON)
  settings.json       ← гучності, хоткеї, ключ Freesound
  sounds\
    starter\night-city\…  starter\elysium\…   ← стартові звуки
    custom\…                                   ← твої файли
```

## Структура коду

| Файл | Що робить |
|---|---|
| `app.py` | точка входу: відкриває вікно (pywebview) |
| `soundboard/audio.py` | аудіорушій на pygame: канали, фейди, режими повтору |
| `soundboard/hotkeys.py` | глобальні хоткеї через WinAPI `RegisterHotKey` |
| `soundboard/api.py` | API, яке викликає інтерфейс |
| `soundboard/store.py` | `presets.json` / `settings.json` |
| `soundboard/starter.py` | стартові дошки й завантажувач із Freesound |
| `ui/` | інтерфейс (HTML/CSS/JS) |
